# Проектные навыки AutoMontage-Agent

Канонические инструкции навыков лежат в `skills/<name>/`. Тонкие адаптеры в `.claude/skills/` и `.codex/skills/` делают один и тот же навык доступным Claude Code и Codex без дублирования длинных инструкций.

## reel-turnkey

Навык «ролик под ключ» ведёт весь lesson-процесс:

1. Проверка исходника и кадрирования.
2. Транскрибация и пруруф.
3. Один полный пакет согласования.
4. Рендер только после явного утверждения.
5. Музыка с sidechain-ducking и финальный QA.

Пример запуска в новом чате:

> Собери ролик под ключ из `/path/to/video.mp4`. Формат вертикальный Reels. Музыка современная ритмичная без вокала. Остальное по дефолтам.

Новые навыки подхватываются при новом запуске агента. Если автоматический триггер не сработал, назови навык явно: `$reel-turnkey`.

## Что попадает в открытый репозиторий

В Git попадают сам навык, публичная тема `lesson-neutral`, семь сцен, схемы и тестовые запросы. В Git не попадают внешние бренд-паки, исходники, музыка, рендеры, ключи и локальная память.
