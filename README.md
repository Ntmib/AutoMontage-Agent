# AutoMontage-Agent 🎬

Движок автомонтажа видео для ИИ-агента (Claude Code / Codex). Скидываешь сырое видео говорящей головы — получаешь готовый ролик: субтитры, анимированные плашки, счётчики, картинки под смысл, полноэкранные врезки, музыка, перекадрирование в вертикаль. Всё локально, стиль настраивается.

Не нужно уметь монтировать и не нужен терминал, всё делает агент по твоему запросу.

📐 <b>Шаблоны и стили</b>: каталог со скринами в [docs/TEMPLATES.md](docs/TEMPLATES.md).
Флагман: <b>lesson-presentation</b> (урок/эфир, 16:9). Свой фирменный стиль подключается
внешней темой (`THEMES_EXT`) и в открытый репозиторий не попадает.

---

## Что умеет

- **Субтитры-караоке** — распознаёт речь, ставит субтитры, подсвечивает текущее слово.
- **Плашки и счётчики** — красивые карточки в твоём стиле: текст печатается, цифры бегут, прогресс-бары заполняются.
- **Картинки по смыслу** — генерирует реалистичные изображения под то, о чём говоришь, и вставляет на весь экран.
- **Скриншот кадра** — на фразе «сделай скриншот» вставляет твой же кадр в окно редактора.
- **Врезки** — человек пропадает, на весь экран идёт картинка/графика, звук продолжается.
- **Режет паузы и слова-паразиты** — речь звучит плотно и по делу.
- **Музыка** — подкладывает фоновую музыку и приглушает её под голос.
- **Горизонт → вертикаль** — сам перекадрирует и следит за лицом (для Reels/Shorts).
- **Чистит звук и картинку** — громкость под соцсети, iPhone-видео не серое.
- **Зум-ритм** — по запросу меняет крупность плана каждые несколько секунд (динамика).
- **Стиль — параметр** — крафт по умолчанию, можно неон или свой (меняется одним словом).

## Установка — просто скажи Claude

Тебе НЕ нужен терминал. Открой Claude Code (или Codex) в пустой папке и вставь этот запрос:

> Установи движок автомонтажа из репозитория AutoMontage-Agent. Склонируй его, поставь зависимости (Node-пакеты, Python-пакет faster-whisper, браузер Chromium для Playwright), скачай шрифты Oswald, JetBrains Mono и Onest. Проверь, что ffmpeg установлен. Когда всё готово — напиши, что можно присылать видео.

Агент всё сделает сам: скачает, поставит, проверит. Если чего-то не хватает (например ffmpeg) — он скажет, что доустановить.

Что должно быть на компьютере заранее (агент проверит и подскажет):
- **Node.js** (18+) и **Python 3** — обычно уже есть или агент поможет поставить;
- **ffmpeg** — бесплатный, агент даст команду под твою систему.

### Установка глобальной командой (Windows / macOS / Linux)

Движок кросс-платформенный. После установки появляется команда `automontage`, доступная **из любой папки**.

```bash
git clone https://github.com/Ntmib/AutoMontage-Agent.git
cd AutoMontage-Agent
npm install            # Node-зависимости
pip install -r requirements.txt   # Python: faster-whisper, opencv, numpy
npm install -g .       # ставит глобальную команду automontage
```

Дальше — из ЛЮБОЙ папки:

```bash
automontage моё-видео.mp4            # результат появится в текущей папке
automontage видео.mp4 --tighten --beat --autopos
automontage --help                  # все опции
```

Пере-генерация картинок-плашек (опционально): скрипты `scripts/shot-*.js` рисуют broll/мок-картинки через Playwright. Основной монтаж их НЕ требует (в репозитории уже лежат готовые картинки). Если хочешь пересобрать их сам — один раз выполни `npx playwright install chromium`.

Особенности по ОС:
- **macOS / Linux** — работает сразу. Если `python3` не находится — поставь через `brew install python` (Mac).
- **Windows** — ставь Node.js и Python с официальных сайтов (при установке Python отметь «Add to PATH»). ffmpeg: `winget install Gyan.FFmpeg`. Команда `automontage` появится автоматически (npm сам делает `.cmd`-обёртку). Временные файлы, пути и запуск — уже адаптированы под Windows.

### 🔑 Ключ OpenAI — для генерации картинок

Чтобы движок **генерировал картинки под смысл речи**, нужен собственный ключ OpenAI (модель `gpt-image`). Это платно — примерно копейки за картинку, платишь напрямую OpenAI.

- Ключ вставляется как переменная окружения `OPENAI_API_KEY`, **в код не пишется и в репозиторий не попадает**.
- **Без ключа движок тоже работает** — просто картинки берутся из готовых/стоковых, а не генерируются под запрос.
- Всё остальное (субтитры, плашки, счётчики, музыка, врезки, вертикаль, зум-ритм) — **бесплатно и без каких-либо ключей**.

Где взять ключ: platform.openai.com → API keys. Скажи агенту «вот мой ключ OpenAI» — он подскажет, как безопасно его подключить.

## Формат ролика = формат исходника

По умолчанию агент делает монтаж в том же формате, что и присланное видео:
- прислал **горизонтальное** (16:9) → получишь **горизонтальное**;
- прислал **вертикальное** (9:16) → получишь **вертикальное**.

Перекадрирование (например, из горизонта в вертикаль со слежением за лицом) делается **только по твоему запросу**. В конце агент может спросить, нужна ли версия в другом формате.

## Большие файлы через Telegram (для тех, кто ставит бота)

Если подаёшь видео через своего Telegram-бота, у облачного Bot API лимит — бот принимает/отдаёт максимум 20–50 МБ. Чтобы работать с большими файлами (до 2 ГБ) прямо в чате:

1. Подними локальный Telegram Bot API сервер (`telegram-bot-api`, есть Docker-образ) на своей машине, например на `localhost:8081`.
2. В настройках своего бота укажи `apiRoot` / `baseApiUrl = http://localhost:8081` (опция есть в grammY, telegraf, node-telegram-bot-api и др.).
3. После этого бот сможет принимать и отправлять большие видео без сжатия.

Без этого большие ролики придётся передавать через облако (Google Drive и т.п.) или в сжатом виде.

## Как пользоваться

1. Пришли агенту видео (говорящая голова). Если файл большой — через ссылку на Google Drive.
2. Скажи, что хочешь. Примеры запросов:

> Смонтируй это видео в моём крафт-стиле. Субтитры, плашки на ключевых словах, музыку lo-fi на фон приглушённую.

> Сделай вертикальный Reels из этого горизонтального видео, следи за лицом. Добавь ритмичный зум — новый план каждые 3 секунды.

> На фразе «сделай скриншот» вставь мой кадр. Сгенерируй 2 реалистичные картинки под смысл.

3. Агент соберёт монтаж и пришлёт готовый ролик.

**Авто-адаптация под видео** (по запросу): агент может сам подстроить цвета графики под палитру твоего ролика (сохранив твой бренд-цвет) и расставить плашки по кадру, чтобы не перекрывали лицо и не были шаблонными. Скажи «подстрой под видео» или «сделай не шаблонно».

Не хочешь ничего расписывать — просто напиши «смонтируй», агент сам предложит вариант и покажет.

## Стиль под себя

По умолчанию — «крафт» (тёплый кремовый + терракот). Хочешь другой — скажи агенту: «сделай в неоновом стиле» или «вот мои цвета: …». Новый стиль добавляется одним файлом-темой за пару минут.

## Распознавание речи — модель на выбор

Субтитры делаются локально моделью Whisper. Модель **скачивается один раз** при первом запуске и дальше работает офлайн (не качается на каждое видео).

| Модель | Вес | Точность (рус) | Когда брать |
|---|---|---|---|
| `base` | ~140 МБ | средняя | слабый сервер, черновик |
| `small` | ~460 МБ | хорошая | лёгкий баланс |
| `large-v3-turbo` | ~1.6 ГБ | почти макс | **по умолчанию** (баланс) |
| `large-v3` | ~3 ГБ | максимум | мощный сервер, чистовик |

По умолчанию — `large-v3-turbo`. Скажи агенту «используй small» или «поставь large-v3» — он переключит. Есть и облачный вариант (без скачивания, но платно и нужен интернет): OpenAI Whisper API / Yandex SpeechKit.

## Под капотом (для любопытных)

Remotion (анимация плашек кодом), faster-whisper (распознавание речи, локально), ffmpeg (звук/видео), Playwright (картинки-плашки), OpenCV (перекадрирование по лицу), gpt-image (генерация картинок). Монтаж описывается простым JSON-«монтажным листом» — стиль и контент разделены.

Подробности установки и разработки — в [HANDOFF.md](HANDOFF.md), дорожная карта — в [PLAN.md](PLAN.md), пошаговые инструкции — в папке [docs/](docs/).
