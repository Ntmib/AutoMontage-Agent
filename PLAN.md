# План: полный шаблон агентного видеомонтажа (AutoMontage-Agent)

Цель: движок, который из «видео + монтажный лист + стиль» собирает готовый вертикальный/горизонтальный ролик с анимированными плашками, счётчиками, субтитрами и broll-врезками. Стиль — параметр (крафт по умолчанию, любой другой по запросу).

## Архитектура (3 слоя)

1. ТЕМА (стиль) — отдельный слой токенов. Меняется одной строкой в запросе.
2. БЛОКИ — библиотека анимированных компонентов (не зависят от темы, берут цвета/шрифты из неё).
3. МОНТАЖНЫЙ ЛИСТ — JSON-сценарий: какой блок, когда, с каким текстом. Генерится из транскрипта + ТЗ.

Разделение стиля и контента = один и тот же ролик рендерится в крафте, в неоне или в любом новом стиле без переписывания блоков.

## Система тем

Каждая тема — объект токенов:
```
{
  name: 'craft',
  colors: { bg, cardBg, cardBg2, accent, accentDark, text, textSoft },
  fonts:  { display: 'Oswald', mono: 'JetBrains Mono', body: 'Onest' },
  radius, shadow, border,
  motion: { style: 'soft', spring: {damping, mass} }   // 'soft' крафт | 'snappy' неон
}
```
- `craft` — БАЗОВАЯ, всегда есть: кремовый #F0EAE0 + терракот #CC785C + коричневый #3D2E24, мягкие тени, без свечения.
- `cyber` — второй пресет для проверки параметризации: графит + лаймовый неон, свечения.
- Новый стиль = новый файл темы (10 минут), блоки не трогаем.

## Библиотека блоков (компоненты)

| Блок | Что делает | Анимации |
|---|---|---|
| LabelTop | верхний лейбл-бренд ">_ ..." | slide-in сверху |
| SubtitleCard | плашка-реплика (обычная/акцент) | pop / выезд, подсветка слова |
| InfoCard | инфо-карточка + прогресс-бар | выезд снизу, typewriter, fill |
| CounterCard | крупный счётчик | count-up 0→N, зум |
| CTACard | финальный призыв + кнопка | pulse, выезд |
| BrollFullscreen | картинка/видео на весь экран | zoom (Ken Burns), fade, подпись |
| CaptionsAuto | авто-субтитры по речи | появление по словам |
| PhoneMock (опц.) | 3D-мокап телефона со скрином | наклон, свечение |

Каждый блок принимает: `{ start, duration, ...content, theme }`.

## Монтажный лист (сердце системы)

JSON — список сцен по таймкодам:
```
{
  "source": "source.mp4",
  "theme": "craft",
  "blocks": [
    { "type": "LabelTop", "start": 0.3, "text": ">_ АНОНС" },
    { "type": "InfoCard", "start": 6.3, "end": 12.6,
      "tag": "// МАРАФОН", "title": "РЕСУРС НА МИЛЛИОН",
      "pills": ["3 дня","бесплатно"], "progress": true },
    { "type": "Broll", "start": 8, "end": 11,
      "image": "growth.png", "caption": "рост за 2,5 месяца" },
    { "type": "CounterCard", "start": 14, "end": 17,
      "label": "ВСЕГО ЛИШЬ", "value": 5, "unit": "минут в день" },
    { "type": "CTACard", "start": 22.6, "head": "ЖМИ НА КНОПКУ", "btn": "ССЫЛКА НИЖЕ ↓" }
  ]
}
```
Remotion читает лист → раскладывает блоки по времени. Меняю лист — меняется монтаж, код не трогаю.

## Пайплайн (одна команда)

```
видео.mp4  ──▶ [1] faster-whisper: транскрипт + таймкоды
           ──▶ [2] сборка монтажного листа (я предлагаю, ты правишь)
           ──▶ [3] (опц.) gpt-image-2: картинки для broll в теме
           ──▶ [4] Remotion render с выбранной темой
           ──▶ [5] выход .mp4 → отправка как ДОКУМЕНТ (аспект сохраняется)
```

## Как ты ставишь задачу

Минимум — просто видео:
> «Смонтируй» → режим A: я сам транскрибирую, собираю лист, показываю на утверждение.

С акцентами:
> «Смонтируй, стиль крафт (или: неон/минимал), выдели 25 000 и 3 дня, на 0:08 картинка роста подписчиков, финал — ссылка ниже»

Поле «стиль» опционально. Не указан → craft.

# ДОРОЖНАЯ КАРТА ДО ФИНАЛА (детально)

Порядок: 4 → 3 → 6 → 8 → 9. Сначала бесплатные и часто нужные вещи (субтитры, пайплайн), потом broll (единственное, что иногда трогает OpenAI), потом обвязка.

## Этап 4 — Авто-субтитры (CaptionsAuto) — БЕСПЛАТНО
Цель: речь автоматически превращается в анимированные субтитры-плашки в стиле темы.
Подзадачи:
- [ ] Конвертер: JSON транскрипта faster-whisper (words + таймкоды) → массив caption-блоков (группировка по 3-5 слов / по паузам).
- [ ] Компонент CaptionsAuto: показывает текущую фразу по времени, слово-в-фокусе подсвечивается accent-цветом (караоке).
- [ ] Позиция/размер/фон — из темы (craft: тёмная плашка + кремовый текст; cyber: неон).
- [ ] Режим «только субтитры» и режим «субтитры + плашки» (чтобы не перекрывались — субтитры уходят выше, когда снизу инфо-карточка).
Критерий готовности: на тестовом ролике субтитры идут синхронно с речью, слово подсвечивается, стиль меняется вместе с темой.
Оценка: средне. Риск: тайминг слов whisper-base неточный → добавить ручную правку в монтажном листе.

## Этап 3 — Broll: полноэкранные врезки — БЕСПЛАТНО (картинка своя) / OpenAI (генерация)
Цель: на заданных секундах человек перекрывается полноэкранной картинкой/видео с движением и подписью.
Подзадачи:
- [ ] Компонент BrollFullscreen: слой на весь кадр, вход fade/slide, живой зум (Ken Burns), выход, подпись-плашка снизу в стиле темы.
- [ ] Источник картинки — 3 варианта: (а) файл, который дал ты; (б) стоковая; (в) gpt-image-2 генерация.
- [ ] Хелпер genImage: промпт учитывает тему (крафт → тёплая палитра, без текста на картинке), quality=high, кириллицу не рисуем (текст добавляем плашкой поверх). Кладёт PNG в public/broll/.
- [ ] Поддержка видео-broll (OffthreadVideo вместо картинки) — врезка чужого клипа/скринкаста.
- [ ] Звук говорящей головы продолжает идти под врезкой.
Критерий готовности: на 2-3 сек человек сменяется картинкой с зумом и подписью, потом возврат; звук не прерывается.
Кредиты: только вариант (в). (а) и (б) — ноль OpenAI. Перед генерацией проверять баланс.
Оценка: средне.

# КРИТЕРИЙ ГОТОВНОСТИ ВСЕГО ШАБЛОНА
1. Присылаю видео (верт. или гориз.) + короткое ТЗ → получаю готовый ролик как документ.
2. Есть субтитры, плашки, счётчики, минимум одна broll-врезка.
3. Смена стиля = одно слово в запросе; craft — дефолт.
4. Весь путь бесплатный, OpenAI только для генерации broll-картинок (и то опционально).
5. Новый стиль добавляется за ~10 минут одним файлом темы.

## Ограничения / решения
- Рендер Remotion тяжелее ffmpeg (~1 fps на CPU). Демо 7с ≈ 1,5 мин. Полный ролик 30с ≈ 5-7 мин → рендерить порционно, не в один foreground-заход.
- Отправка ТОЛЬКО документом ([ФАЙЛ:]) — иначе Telegram сплющивает вертикаль.
- Аспект наследуется от исходника автоматически.
- OPENAI-кредиты для gpt-image-2 нужны активные (на 2026-08-01 были исчерпаны — проверить перед этапом 3).

## Итог
База — крафт, жёстко зашита как дефолтная тема. Любой другой стиль = смена одного параметра `theme`. Контент (что и когда показать) живёт в монтажном листе отдельно от стиля и от кода блоков.
