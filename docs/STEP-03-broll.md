# Этап 3 — Broll: полноэкранные врезки. Инструкция исполнения

Цель: на заданных секундах поверх говорящей головы появляется полноэкранный слой (картинка/видео) с живым зумом и подписью. Звук исходника продолжает идти (broll — визуальный слой поверх фонового OffthreadVideo в Timeline).

## Ключевые решения
- Звук НЕ трогаем: в Timeline OffthreadVideo играет всегда, broll просто перекрывает картинку.
- Источник картинки — 3 варианта: (а) файл от Димы; (б) локальная крафт-иллюстрация (HTML→PNG, 0₽); (в) gpt-image-2 (только по явному ОК, тратит кредиты).
- Для демо этапа — вариант (б): сгенерить growth.png локально в крафт-палитре.

## Шаги
1. Локальная картинка: scripts/broll-growth.html (720x1280, кремовый фон, восходящий SVG-график терракотом, иконки/точки) → Playwright PNG → public/broll/growth.png.
2. Компонент src/blocks/BrollFullscreen.jsx:
   - пропсы: `image` (путь в public), `caption` (подпись), `from`/`to` берутся из Sequence.
   - localFrame = useCurrentFrame() (Sequence from=0 внутри врезки).
   - вход: fade + лёгкий slide/scale (первые ~0.4с); выход: fade (последние ~0.4с) — по durationInFrames.
   - Ken Burns: непрерывный zoom 1.05→1.15 по длине врезки.
   - подпись-плашка снизу в стиле useTheme (mono lowercase, accent-плашка).
   - поддержать `video` (OffthreadVideo) как альтернативу image — врезка чужого клипа.
3. Зарегистрировать BrollFullscreen в blocks/index.js.
4. Демо: scenario-broll.js (LabelTop + CaptionsAuto + Broll на 6.2–9.5с «ресурс на миллион»/«3 дня») + Composition "ReelBroll" в Root (360 кадров).
5. Рендер `ReelBroll`, извлечь кадры, проверить: человек перекрыт картинкой, зум идёт, подпись в стиле, потом возврат к говорящей голове.
6. Хелпер genImage (для варианта в, НЕ запускать без ОК): scripts/gen-broll.sh — gpt-image-2 (проверить новейшую модель через /v1/models), quality=high, промпт «в крафт-палитре #F0EAE0/#CC785C, тёплый, БЕЗ текста, без букв», размер 1024x1536 → public/broll/. Текст добавляем плашкой поверх, не генерацией.
7. Коммит. Отправить Диме как ДОКУМЕНТ.

## Критерий готовности
На врезке (2-3с) человек сменяется полноэкранной картинкой с зумом и подписью, звук не прерывается, потом возврат. Стиль подписи наследуется темой.

## Риски
- Картинка перекрывает лицо полностью → это и есть эффект; для «картинка в углу» сделать отдельный вариант позже.
- gpt-image кириллицу пишет криво → правило: текст НЕ генерим, кладём плашкой (наш шрифт).
