# Этап 4 — Авто-субтитры (CaptionsAuto). Инструкция исполнения

Цель: речь → анимированные субтитры-плашки в стиле активной темы, слово-в-фокусе подсвечивается accent-цветом (караоке). Всё бесплатно.

## Вход
- transcript.json от faster-whisper (есть: ./tmp/reel2/transcript.json), формат:
  `[{start,end,text,words:[{w,s,e}]}, ...]` — слова с таймкодами (сек).

## Шаги
1. Скопировать transcript.json в проект → src/data/transcript.json.
2. Конвертер scripts/build-captions.js (node):
   - пройти все words, группировать в фразы по правилу: набирать пока (слов < 4) И (длительность группы < 1.6с) И (пауза до след. слова < 0.45с);
   - на разрыве закрыть группу;
   - результат: `[{start,end,words:[{w,s,e}]}]` → записать в src/data/captions.js как `export const CAPTIONS = [...]`.
   - чистка: убрать пустые, привести пробелы.
3. Компонент src/blocks/CaptionsAuto.jsx:
   - пропсы: `groups` (массив), `position` ('bottom' по умолч., отступ снизу настраиваемый `offset`).
   - t = useCurrentFrame()/fps (блок вставляется в Sequence from=0 → локальный = глобальный кадр).
   - найти активную группу (g.start ≤ t ≤ g.end + хвост 0.15с);
   - отрисовать её слова в плашке; слово где (w.s ≤ t ≤ w.e) — accent-цвет + лёгкий scale;
   - вход плашки: pop (springIn), стиль/цвет/шрифт из useTheme (craft: тёмная плашка milk-текст; cyber: неон);
   - шрифт: display uppercase, крупный, перенос по словам, максимум 2 строки.
4. Зарегистрировать CaptionsAuto в src/blocks/index.js.
5. Демо: отдельный src/scenario-captions.js (LabelTop + CaptionsAuto с CAPTIONS), вторая Composition "ReelCaptions" в Root.jsx (durationInFrames под длину транскрипта, source.mp4).
6. Рендер: `npx remotion render src/index.js ReelCaptions out/reel_captions.mp4 --codec=h264`.
7. Проверка: извлечь 3-4 кадра, глазами убедиться — субтитры синхронны речи, слово подсвечивается, кириллица чистая.
8. Коммит после каждого рабочего куска. Отправить Диме как ДОКУМЕНТ.

## Критерий готовности
Субтитры идут по речи, текущее слово выделено, стиль наследуется темой (проверить и craft, и хотя бы кадр cyber).

## Риски / решения
- Тайминг whisper-base неточный → допускаю ручную правку групп; хвост +0.15с чтобы фраза не мигала.
- Перекрытие с нижними плашками → у CaptionsAuto свой offset выше (bottom ~ 520), в пайплайне валидатор развёдет.
- Длинные слова/фразы → clamp на 2 строки, размер шрифта из темы.
