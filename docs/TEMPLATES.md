# Шаблоны монтажа (Templates)

Движок собирает ролик по ВЫБРАННОМУ шаблону. Шаблон = композиция (layout) + тема (стиль).
Формат наследуется от исходника, если не сказано иначе.

Как выбрать шаблон при монтаже: скажи агенту тип ролика и стиль, либо укажи флагом
`--template <id>` (и `--theme <id>` для скина). Ниже каталог открытых шаблонов со скринами.

---

## Открытые шаблоны (в этом репозитории)

### 1. lesson-presentation :: Урок / эфир (16:9)
Спикер в карточке слева + авто-слайды справа (номер, заголовок, дословная ключевая
фраза из речи, буллеты, чипы). Слайды генерятся из транскрипта, спикер центрируется
в карточке автоматически. Идеально для разбора эфира/вебинара в «видео-презентацию».

![lesson-presentation](previews/lesson-presentation.png)

- Композиция: `LessonSeq` · Тема по умолчанию: `lesson-neutral`
- Пайплайн: `node scripts/build-lesson.js <видео> [--theme <id>] [--title "ТЕМА"]`
  (транскрипт, затем gen-slides.js, затем центрирование лица, затем рендер)

### 2. reel-captions :: Вертикаль: говорящая голова + субтитры (9:16)
Спикер на весь экран + караоке-субтитры по словам + плашки/счётчики/врезки.
Для Reels/Shorts/TikTok. Скины: `craft` (кремовый) и `cyber` (тёмный неон).

![reel-captions](previews/reel-captions.png)

- Композиция: `Dynamic` / `Preview` · Темы: `craft`, `cyber`
- Пайплайн: `node scripts/build.js <видео> [--theme craft|cyber]`

### 3. highlight :: Крупная цитата (9:16 / 16:9)
Минимал: одна дословная фраза спикера крупно на фоне + подпись. Для нарезок-хайлайтов
и цитат. Скины нейтральные.

![highlight](previews/highlight.png)

- Композиция: `Highlight` · Тема: `lesson-neutral`
- Статус: в сборке (скрин появится после первого рендера)

## Свой фирменный стиль (внешние темы)

Тема может лежать ВНЕ этого репозитория и подключаться без изменения кода:

```
THEMES_EXT=/путь/к/бренд-паку   # папка с <theme-id>/theme.json
node scripts/build-lesson.js видео.mp4 --theme <theme-id>
```

`getTheme` принимает тему объектом (`theme.json`), поэтому фирменные палитры, шрифты и
декор подключаются локально и НЕ попадают в открытый репозиторий. Так каждый может
собрать свою тему поверх открытых шаблонов, а автор бренда держит стиль приватно.
См. пример структуры темы в `src/theme/lesson-neutral.js`.
